Waves

Red-outlined tasks need the owner's go-ahead before their outward step (deleting branches, going public, disclosure, filing upstream).

R-numbered nodes are review gates: an adversarial review of the whole project, an advisor pass, then a plan update. A gate waits for its milestone and blocks the next milestone's tasks that haven't started.

The critical path is the longest chain by task count; tasks have no size estimates, so treat it as a guide to ordering, not to time.
